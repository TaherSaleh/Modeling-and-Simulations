# Modeling-and-Simulations
Modeling and simulation (M&amp;S) is the use of models (e.g., physical, mathematical, behavioral, or logical representation of a system, entity, phenomenon, or process) as a basis for simulations to develop data utilized for managerial or technical decision making.(wiki)

This repository serves as the main hub for my modeling, simulation, and CAD work—including system simulations built in [AnyLogic](https://anylogic.com), and 3D parts, assemblies, and technical drawings created in [Onshape](https://onshape.com).

## Repository Structure
* [`/anylogic-simulations`](./Anylogic-Simulations) – Discrete-event, agent-based, and system dynamics models.
* [`/Onshape-CAD`](./Onshape-CAD) – 3D parametric models, assemblies, and 2D engineering drawings.
